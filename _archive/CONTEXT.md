# _archive — preserve retired records

One job: preserve superseded plans and legacy task memory outside the active route.

## Inputs

- Superseded files approved for archival

Do NOT load: archive content during normal change work.

## Process

1. Preserve the original file content and name.
2. Keep archived material outside `work/active/` and `work/closed/`.
3. Link to an archived file only when historical evidence is required.

## Outputs

- Retired plans in `legacy-roadmap/`
- Retired task logs in `legacy-memory-bank/`

## Human check

Confirm that no active contract or record depends on an archived path.
